# Quant System Dashboard v1 ImageGen Prompt

Use case: ui-mockup  
Asset type: desktop web application high-fidelity design mockup for a personal quantitative trading core system

Primary request: Create one polished 16:9 desktop dashboard interface for a serious, safety-first quantitative trading system. The product is not a crypto exchange and not a flashy trading terminal. It supports the workflow Research → Backtest → Approval → Execution → Review.

Scene/backdrop: full-screen desktop browser application, no browser chrome, 1440px-style layout.

Style/medium: premium enterprise fintech SaaS UI, high-fidelity Figma-style product mockup, precise grid, restrained and highly legible.

Composition/framing: fixed 232px left sidebar; compact top header; main 12-column dashboard. Left navigation items in Simplified Chinese: “总览”, “策略研究”, “回测实验”, “信号审批”, “组合风险”, “订单执行”, “复盘报告”, “系统设置”. Main page title: “量化策略中枢”. Top KPI cards: “账户净值”, “主动风险预算”, “相对 SPY”, “数据健康”. Large center chart comparing portfolio equity and SPY benchmark with two clean lines. Right-side amber/red safety card titled exactly “历史错误警告” with compact status rows for benchmark framework, theme concentration, order chasing, execution window, re-entry rule. Below, a wide approval queue titled “待审批信号” with a compact table containing columns for 标的, 策略, 仓位类型, 信号, 最大亏损, 合并风险, 执行窗口, 状态. Include two sample rows SPY and NVDA only. Include clear secondary button “查看计划” and one primary button “进入审批”; no direct buy/sell button. Bottom section shows strategy lifecycle stages “研究 / 验证 / 模拟 / 影子 / 受限实盘” and a small risk exposure breakdown by core, active, and cash.

Color palette: deep navy `#0B1220` background, slate `#111C2E` cards, cool gray text, white primary text, blue `#4F8CFF` for portfolio, muted violet for benchmark, emerald only for validated positive status, amber for warnings, red only for hard blocks.

Typography: modern Chinese sans serif, medium density, readable at a glance, tabular numerals.

Lighting/mood: calm, institutional, trustworthy, disciplined.

Constraints: preserve generous spacing, 8px grid, 12px card radius, subtle 1px borders, almost no shadows. Show risk before return. Show human approval as a required gate. No real broker logo, no company logo, no people, no device mockup, no watermark. Use only the listed Chinese labels and symbols; keep other microcopy minimal.

Avoid: neon cyberpunk, black-and-green hacker terminal, excessive candlesticks, glowing effects, cryptocurrency imagery, huge PnL numbers, casino aesthetics, clutter, tiny unreadable text, direct market order buttons, autonomous trading claims.
